Movavi Effect Builder v0.13.2 — сборки, каталог, пакетное видео

Веб-версия: https://tonysabbatony.github.io/movavi-effect-builder/
После публикации новой версии перезагрузите страницу. Перед обновлением
экспортируйте свою сборку: изменения хранятся в памяти вкладки.
Для автономного запуска нужен Python 3 и START_MAC.command / START_WINDOWS.bat.
Скачанный ZIP не обновляется автоматически.

Новая сборка создаёт первый пресет; + Пресет добавляет следующие.
Можно открыть прежнюю папку или ZIP. Все эффекты — в одном каталоге:
Adjust, Bloom, Sharpen, Aberration, LUT, Overlay, VHS, Soft Blur, Noise,
Duotone, False Color, Posterize Time. Пример Dreamy — в меню «Ещё».
Оверлей MP4/MOV и LUT CUBE можно выбрать из любой папки компьютера.
Они упакуются вместе с пресетом. Тестовое фото/видео в пакет не попадает.

Экспорт сборки ZIP: все пресеты, all_in_one.json + Layers.zip.
Ещё → ZIP выбранного пресета: тот же формат, один пресет.
Экспорт видео: выбранный клип, один пресет или вся сборка, Before/After,
подписи и звук. Для всех пресетов создаётся ZIP с папками и их именами.
Оставляйте вкладку открытой до завершения. Все файлы обрабатываются локально.

Фирменное оформление: официальный зелёный знак Movavi Mobile, #89FE00,
шрифт Aeroport. Источники закреплены в BRAND_GUIDELINES.md.
VHS/Soft Blur/Noise: приблизительный веб-предпросмотр, штатный мобильный экспорт.
Posterize Time: 100% = 5 fps, 50% = 17,5 fps, 0% = исходные кадры.
В настройках слоя — интенсивность; смешивания кадров нет.
Для него требуется интеграция шейдеров и управления историей в приложении.
Подробности — README.md и prototypes/posterize-time/README_RU.md.

Movavi Effect Builder v0.12 — мобильные расчёты preview

Актуально для v0.12 — 28.10.2026
--------------------------------
Исправлены общие расчёты редактора для всех десяти пресетов Dreamy rework.
Художественные настройки эталона не подгонялись и не перезаписывались.

ЗАПУСК
Запустите START_MAC.command / START_WINDOWS.bat именно из папки v0.12.
В заголовке вкладки должно быть Movavi Effect Builder v0.12.
Launcher печатает версию, полный путь и новый URL. Старая вкладка v0.11
продолжает показывать старый preview. Локальный сервер отключает кеширование.
Встроенная «Рабочая подборка Dreamy ×10» теперь является точной копией
подтверждённого мобильного эталона; она не смешивается со старой Glow-подборкой.
Можно открыть и свою папку с all_in_one.json + Layers.zip / деревом Layers.

ЧТО ИСПРАВЛЕНО
1. Adjust использует пять мобильных стадий: коррекция яркости/экспозиции/
   контраста, HSL, тени/света в Lab, цветовая температура, гамма Y'PbPr.
   Учтены диапазоны iOS binding, перестановка brightness/exposure, температурные
   коэффициенты, обратное направление blackPoint, переходы Rec.709/linear,
   RGBA8 и half-float промежуточные значения. Общая сила и фиксированные
   параметры продолжают вычисляться по исходным JSON.
2. Связанные параметры ISF считаются как MIN + общая_сила × (MAX − MIN).
   DEFAULT для них мобильный загрузчик пересчитывает перед рендером.
   Например, Glow 3 в эталоне имеет intensity DEFAULT 0.29, MIN 0, MAX 0.8.
   На телефоне при 100% применяется 0.8. Теперь preview и поле Intensity
   показывают именно это значение. При открытии JSON не переписывается.
3. Чтение LUT повторяет аппаратную координатную сетку мобильной 3D-текстуры.
   Мобильный загрузчик выбирает локальный .cube по имени слоя и использует
   Trilinear. templateID не подменяет локальный файл.
4. Сам алгоритм Bloom сохранён: он побайтово совпадает с переданным v3.
   Изменилось подтверждённое правило применения общей силы вокруг него.

КАК РЕДАКТИРОВАТЬ INTENSITY
Если «Фиксировать» выключено, основной регулятор задаёт силу при 100%:
он записывает MAX и согласованный DEFAULT. Поля «При 0%» / «При 100%»
редактируют MIN / MAX. Например, MIN=0, MAX=0.5 дают силу 0.25 при 50%.
Если «Фиксировать» включено, применяется постоянный DEFAULT при любой
общей силе. Для остальных пяти фиксированных параметров регулятор меняет
DEFAULT. Можно явно связать и их, сняв «Фиксировать».
Reset Layer возвращает весь исходный ресурс: DEFAULT, MIN, MAX,
intensityParamNames, граф проходов и остальные поля.
Ранее заявленное «все шесть регуляторов меняют только DEFAULT» заменено
этим описанием: для связанного параметра такая редактура была нерабочей.

СОХРАНЕНИЕ И ТЕЛЕФОН
Экспорт группы и выбранного пресета из коллекции сохраняет мобильный формат:
внешний ZIP содержит all_in_one.json и Layers.zip; внутри Layers.zip — дерево
Layers/video_effects/v1/composite_effect/...
Рецепты используют new_bloom_01 / isf, ресурс содержит полный shaderConfig.
Импорт эталона и экспорт без правок сохраняют все художественные значения.
Открытие/сохранение на компьютере не обновляет телефон автоматически.
После своих правок экспортируйте пакет и обновите его в приложении обычным
способом. Для уже установленной Dreamy rework художественные правки не нужны.

ПРОВЕРКИ
Все 10 пресетов × 0/50/100%: 180 значений ISF; реальные UI правки всех шести
параметров, fixed/linked, точный reset, export/reimport.
На Apple M4: исходные Metal-ядра Adjust/LUT и переданный native Bloom v3.
Две группы кадров: синтетическая таблица и один кадр IMG_4987.MOV на 1.000 с.
180 сравнений стадий: Adjust max 4/255, LUT max 1/255, Bloom max 1/255.
Для Adjust среднее отклонение в худшем случае меньше 0.07/255.
Golden-таблицы синтетического кадра включены в test-assets/native-mobile.
Личный кадр видео в архив редактора не включён.
Подробные источники и воспроизводимые команды — MOBILE_RENDER_SOURCES.txt
и VALIDATION.md. Полная цепочка на самом телефоне на синхронном кадре
независимо не измерялась; HDR/P3 и системный декодер не калибровались.

Movavi Effect Builder v0.11 — мобильный контракт ISF Bloom2

Актуально для v0.11 — 28.10.2026
-------------------------------
1. Запустите START_MAC.command / START_WINDOWS.bat.
   Важно: запускайте файл из папки Movavi_Effect_Builder_v0.11, а не v0.10.
   В заголовке вкладки должно быть v0.11, под preview — ISF Bloom2 preview.
   Launcher печатает версию, полный путь и URL; порт выбирается автоматически.
   Если открыта старая вкладка, используйте новый URL из окна launcher.
2. Нажмите «Открыть сборку» и выберите папку с all_in_one.json и Layers.zip.
   Также поддерживается распакованная папка Layers рядом с all_in_one.json.
   Если рядом лежат и Layers.zip, и распакованная Layers, одинаковые файлы
   принимаются. Если содержимое различается, импорт укажет конфликтующий файл.
3. Выберите пресет, добавьте фото/видео, настройте New Bloom и остальные слои.
4. «Экспорт всей группы ZIP» создаёт архив с двумя файлами в корне:
   all_in_one.json и Layers.zip. После распаковки внешнего ZIP эти два файла
   готовы к передаче разработчику. Внутри Layers.zip находится дерево
   Layers/video_effects/v1/composite_effect/Glow_Preset_XX/...
   Экспорт выбранного пресета из коллекции использует тот же вложенный формат.

New Bloom сохраняется как effectName: new_bloom_01, effectType: isf.
Ресурс использует shaderPath: v1/Bloom2/Bloom2, intensityParamNames и полный
shaderConfig с INPUTS и 16 PASSES из проверенной сборки разработчика.
Threshold, Intensity, Radius, Knee, Scatter и Opacity меняют только DEFAULT
соответствующего INPUT. MIN/MAX, PASSES и остальные поля не переписываются.
Reset восстанавливает значения Bloom2, которые были при открытии сборки.

Старые bloom / bloomRework автоматически переводятся в этот контракт.
Их actualValue переносится в DEFAULT; отсутствующие Knee/Scatter/Opacity
получают 0.5/0.65/1. Старые кривые intensityMin/intensityMax/hardCoded
не имеют прямого соответствия контракту Bloom2 и в новый ресурс не переносятся.
intensityParamNames нового ресурса содержит intensity, как в эталоне.
Остальные эффекты, их параметры и файлы сохраняются.

Preview New Bloom использует существующий браузерный рендер через адаптер
ISF DEFAULT. Общая сила масштабирует DEFAULT параметров из intensityParamNames.
Это визуальная проверка редактора, а не гарантия попиксельного совпадения
с мобильным приложением. В самом приложении используется встроенный Bloom2.

При импорте Layers.zip исходная сборка открывается только для чтения:
сохранение выполняется экспортом нового пакета. Исходный ZIP не перезаписывается.
Файлы v0.10 и эталон разработчика при подготовке v0.11 не изменялись.

Проверки: test-launcher.py, test-package-import.cjs, test-ranges.cjs,
test-mobile-contract.cjs, test-migration-e2e.cjs,
test-mobile-e2e.cjs, verify-mobile-package.py; подробности в VALIDATION.md.

Movavi Effect Builder v0.10 — экспорт видео и контракт New Bloom Metal v3

Новое в v0.10 — 27.10.2026
--------------------------
ЭКСПОРТ ВИДЕО
1. Откройте сборку и добавьте тестовое видео.
2. Настройте пресет и нажмите «Экспорт видео…» рядом с Play.
3. Выберите After (с эффектами), Before (исходник) или Before / After рядом.
4. По желанию оставьте подписи в кадре и исходный звук. Нажмите «Экспортировать».
5. Скачивается MP4, если браузер поддерживает запись MP4, иначе WebM.
   Название: Glow_Preset_01_ИмяКлипа_Before_After_ДатаВремя.mp4.
   При блокировке скачивания нажмите «Скачать видео ещё раз» в окне экспорта.

Записывается выбранный клип целиком с начала до конца, с текущей общей силой,
Solo и включёнными в preview слоями. Текущее положение и состояние Play/Pause
восстанавливаются после записи или отмены. Исходный звук можно убрать галочкой;
звуковая дорожка Noise-оверлея не добавляется. Видео скачивается в обычную папку
загрузок браузера; кнопка «Папка для ZIP» относится только к архивам эффектов.

Экспорт предназначен для просмотра и согласования. Разрешение каждого видео
совпадает с обработкой preview: до 960 px по длинной стороне. В режиме рядом
два таких кадра сохраняются рядом; подписи добавляются сверху без обрезки кадра.
Целевая частота 30 кадров/с, но фактическая плавность зависит от скорости эффектов.
Запись идёт примерно столько же, сколько длится ролик. Не скрывайте вкладку:
при скрытии запись отменяется с объяснением. Кнопка «Отменить» и Escape отбрасывают
незавершённый файл. Предел одной записи — 512 МБ. Длинные записи не проверены.
На фото кнопка недоступна. Для записи нужен клип с известной конечной длительностью.
Рекомендуется Chrome. Всё работает локально, в том числе при открытии index.html;
исходное видео, JSON и ZIP на сервер не отправляются.

NEW BLOOM METAL v3
bloom-rework.js побайтно совпадает с браузерным эталоном в архиве
«METAL ВЕРСИЯ v3 — ПЕРЕДАТЬ В РАЗРАБОТКУ.zip» от 01.10.2026.
SHA-256: 3313649548d4a1a8c0f975929e2aa99b999db5cab96fbfd34a44a0280ea8fd06.
Алгоритм и диапазоны не заменены. JSON: effectType=bloomRework, шесть параметров
threshold, intensity, radius, knee, scatter, opacity с actualValue, intensityMin,
intensityMax и hardCoded. Для фиксированных параметров при открытии и сохранении
служебные intensityMin/intensityMax теперь равны actualValue. Это убирает оставшиеся
от старого Bloom неиспользуемые значения -1, не меняя применяемое значение.
Связанные параметры и их исходные границы остаются без изменений.

Имя ресурса произвольное: effectName указывает на resources/<effectName>.json.
Редактор сохраняет пользовательские имена. В отдельно подготовленной копии DREAMY
используется new_bloom_01, как в примере v3, и обновлены все ссылки в манифесте.
Имя bloom_01 само по себе не является ошибкой по предложенному контракту.
Наличие правильного JSON не подтверждает наличие обработчика bloomRework в конкретном
билде TestFlight. Пакет пресетов не устанавливает нативный шейдер. Если слой пропускается,
разработчику нужно проверить регистрацию типа, лог чтения JSON и цепочку запуска Metal.
В текущей сессии iPhone/TestFlight не запускались; причину пропуска слоя в нём не установили.


Новое в v0.9 (сохранено)
-----------------------
Все ползунки и числовые поля доступны и без галочки «Фиксировать».
Без галочки верхнее поле задаёт значение при 100% общей силы; в JSON
обновляется intensityMax (для ISF Sharpen — MAX). Текущее применяемое
значение показано отдельно и меняется между «При 0%» и «При 100%».

При снятии фиксации начальная точка выставляется нейтральной, а значение
при 100% берётся из постоянного значения параметра. При включении фиксации
замораживается текущее применяемое значение. Для Adjustment нейтральная
точка — .5; для силы LUT, Bloom, Noise, резкости и аберрации — 0.
Для порога New Bloom начальная точка — 1, для overlap аберрации — 1.
Параметры размера и формы сами по себе не всегда выключают эффект:
полное исчезновение определяется прежде всего его силой/непрозрачностью.

Начальные значения связанных параметров существующего JSON сохраняются при открытии.
Если эффект остаётся при общей силе 0% из-за ненулевой начальной точки,
нажмите «Нейтрально при 0%»: редактор исправит начальные точки связанных
параметров текущего пресета и сохранит фиксированные значения.

Reset Layer теперь возвращает стандартные настройки редактора, независимо
от значений в загруженном/сохранённом пресете:
- Adjustment: все 11 параметров .5, связаны с общей силой от .5 до .5.
- New Bloom: threshold=.3, intensity=.8, radius=75, knee=.5, scatter=.65,
  opacity=1; интенсивность связана от 0, остальные параметры фиксированы.
- Sharpen: sharpenAmount=.2 (связано от 0), stepSize=.0008 (фиксировано).
- Aberration: strength=.015 (связано от 0), overlap=.3 (фиксировано);
  эти числовые значения совпадают с SettingsEffectChromaticAberrationMultiPass.h.
- LUT: интенсивность 1 (связано от 0), Trilinear; выбранный .cube сохраняется.
- Overlay: интенсивность .2 (связано от 0), screen, center; видео сохраняется.
Для прочих импортированных типов без описанных дефолтов восстанавливаются
исходные значения JSON; сообщение внизу явно указывает этот режим.

Отдельное правило мобильного движка сохранено для видеооверлея: при общей
силе 0% слой Overlay отключается целиком даже с фиксированным значением.
Его параметр остаётся постоянным, но сам слой исключается приложением.

Новое в v0.8 (сохранено)
-----------------------
Кнопка «×» справа от слоя удаляет его из рецепта и превью. Кнопка
«Вернуть слой» отменяет последнее удаление в текущем пресете. Несколько
удалений можно отменять по очереди в этом сеансе. В JSON и ZIP удалённого
слоя в effects не будет. Файлы ресурсов сохраняются для других слоёв
и возможности отмены; удаление файлов с диска автоматически не выполняется.

В слое LUT появился постоянно доступный ползунок «Интенсивность LUT».
Если LUT связан с общей силой, этот ползунок задаёт интенсивность при
100% общей силы. Включите «Фиксировать значение», чтобы интенсивность
LUT задавалась независимо. Настройки сохраняются в штатном JSON.

Кнопка «Добавить фото / видео» позволяет выбрать сразу несколько файлов.
Над превью появляется список с номерами и стрелками «предыдущий/следующий».
Повторная загрузка дополняет список. Выбранное видео запускается само;
эффекты и их настройки сохраняются при переключении тестовых файлов.
Список тестовых файлов хранится в текущем сеансе браузера. Эти фото и
видео не добавляются в мобильный ZIP — в нём остаются ресурсы эффектов.

Старый Bloom и переключение между версиями убраны из редактора. При
открытии прежней сборки слои bloom заменяются на bloomRework. Сохраняются
исходные threshold, intensity и radius; добавляются фиксированные knee=.5,
scatter=.65 и opacity=1. Это новые настройки для нового алгоритма,
а не обещание совпадения картинки со старым Bloom. Конвертация попадёт
на диск после «Сохранить JSON» или в новый экспортированный ZIP.

Исправлено: «+ Sharpen» и импорт Sharpen.ps / Sharpen.vs работают при
прямом открытии index.html. Проверенные исходники и настройки включены
в sharpen-assets.js и больше не загружаются через fetch.

Можно открыть index.html двойным щелчком и затем выбрать папку своей
сборки. Кнопка «Новая подборка Glow ×10» в этом режиме попросит выбрать
папку workspace/Glow_Edit_Main_v2, расположенную рядом с index.html.
При запуске через START_MAC.command подборка открывается автоматически.

1. Полностью распакуйте папку и запустите START_MAC.command на Mac
   или START_WINDOWS.bat на Windows. Нужен Python 3; браузер — Chrome.
2. Новая подборка из 10 пресетов откроется автоматически. Если она не
   открылась, нажмите «Новая подборка Glow ×10».
3. Загрузите фото или видео. Выберите пресет и нужный слой в списке.
4. New Bloom и Sharpen уже добавлены во все 10 пресетов.
5. Чтобы получить сборку для приложения, нажмите «Экспорт всей группы ZIP».
   В корне этого ZIP находятся all_in_one.json и Layers, без внешней папки.

Что сохраняется
---------------
В новых пресетах New Bloom — самостоятельный слой типа bloomRework.
Все шесть параметров сохраняются в resources/new_bloom_01.json и ZIP.
Порядок слоёв сохраняется в Glow_Preset_XX.json.
Sharpen имеет JSON, Sharpen.ps и Sharpen.vs в resources каждого пресета.
В all_in_one.json автоматически обновляется список файлов resources.
ZIP выбранного пресета также имеет манифест и структуру Layers.

Sharpen
-------
Для дополнительного слоя нажмите «+ Sharpen». Вручную писать JSON не нужно.
Также можно импортировать исходные Sharpen.ps / Sharpen.vs из этой сборки:
редактор создаст конфигурацию сам. Другой произвольный шейдер требует
своей конфигурации и реализации preview.
Параметры: сила резкости (0…2 в редакторе) и размер детали stepSize
(0….02, нормализованные координаты, не пиксели). Это выбранные диапазоны
редактора; верхние пределы движка в переданных исходниках не заданы.

Галочка «Фиксировать»
--------------------
Для New Bloom используется штатный контракт actualValue / intensityMin /
intensityMax / hardCoded. Без фиксации параметр меняется от значения
«При 0%» к значению «При 100%».
У Sharpen применяется существующий ISF-контракт: DEFAULT / MIN / MAX
в shaderConfig.INPUTS, а связь с общей силой задаёт intensityParamNames.
Галочка в интерфейсе автоматически записывает именно этот формат.

Два режима открытия
------------------
Встроенная подборка открывается для работы через экспорт ZIP. Чтобы
продолжить позже, сохраните ZIP, распакуйте его и откройте эту папку
кнопкой «Открыть сборку». Прямое «Сохранить JSON» доступно для папки,
открытой с разрешением на запись. При перезагрузке страницы несохранённые
настройки встроенной подборки не восстанавливаются.

Совместимость с приложением
--------------------------
Пользователь подтвердил интеграцию New Bloom и Sharpen в TestFlight.
В JSON используется effectType: bloomRework и штатный ISF Sharpen с
shaderPath: v1/Sharpen/Sharpen. Копии .ps/.vs в resources сопровождают
пресеты, но проверенный код приложения загружает ISF из своего bundle.
Нужна та TestFlight-сборка, в которой эти шейдеры уже встроены.

Подборка — начальные авторские настройки для визуальной проверки на
рабочих видео. В браузере используется до 960 px по длинной стороне и
8 бит на канал. Полное совпадение всей цепочки с iPhone не подтверждено:
Adjust пока приближённый, LUT и Overlay требуют сверки на устройстве.
Значки глаза и Solo временно меняют только preview; слои остаются в рецепте.
Для удаления из рецепта используйте «×».

Встроенная подборка использует полноценный слой bloomRework, который
экспортируется вместе со всеми шестью параметрами.
