# Movavi Effect Builder v0.13.1

Редактор сборок эффектов для Movavi Mobile: создание с нуля, импорт готовых пакетов, предпросмотр и экспорт для разработчиков.

## Открыть билдер

Веб-версия публикуется через GitHub Pages: https://tonysabbatony.github.io/movavi-effect-builder/ . Для работы рекомендуется актуальный Google Chrome с WebGL2.

После публикации обновлений перезагрузите страницу. Открытая вкладка показывает уведомление о новой версии; перед обновлением экспортируйте свою сборку. Рабочие изменения хранятся в памяти вкладки и не синхронизируются между людьми или компьютерами. Фото, видео, LUT и оверлеи обрабатываются локально в браузере.

Для автономного запуска скачайте ZIP из [Releases](https://github.com/tonysabbatony/movavi-effect-builder/releases), распакуйте, установите Python 3 и запустите `START_MAC.command` / `START_WINDOWS.bat`. Или выполните `python3 serve.py`. Скачанная копия не обновляется автоматически.

## Работа со сборкой

1. Нажмите **Новая сборка** и задайте название, ID группы и имя первого пресета. Или откройте готовую папку / ZIP с `all_in_one.json` и `Layers.zip` либо распакованной `Layers`.
2. Добавляйте пресеты кнопкой **+ Пресет**. В каталоге доступны Adjust, New Bloom, Sharpen, Chromatic Aberration, LUT, Overlay, VHS Distortion, Soft Blur, Noise Lee Cranston, Color Duotone, False Color и Posterize Time.
3. Добавьте тестовое фото/видео. Настраивайте слои и общую силу, меняйте порядок. Глаз и Solo относятся только к предпросмотру. Пример Dreamy из десяти пресетов доступен в меню **Ещё**.
4. Для Overlay выберите MP4/MOV из любой папки; для LUT — CUBE. Эти файлы включаются в ресурсы пресета при экспорте. Тестовый исходник туда не попадает.
5. **Экспорт сборки ZIP** сохраняет все пресеты. В **Ещё → ZIP выбранного пресета** можно сохранить один. Внешний архив всегда содержит `all_in_one.json` и `Layers.zip`; внутри — `Layers/video_effects/v1/composite_effect/<UID>/…`.

При импорте сохраняются исходные UID, имена эффектов, типы, пути шейдеров, группы, приоритеты и графы проходов. Новые слои получают свободные имена. LUT пакуется как `<effectName>.cube`, оверлей связывается по имени файла без расширения. Совпадающие имена разных видео получают суффикс, исходный ресурс не перезаписывается. Пакет можно снова открыть через **Открыть ZIP**.

## Видео для согласования

**Экспорт видео…** работает с выбранным тестовым клипом. Доступны Before / After рядом, только After и только Before, подписи и исходный звук.

- Текущий пресет: учитываются общая сила, Solo и выключенные слои.
- Все пресеты: каждый рендерится со всеми своими слоями и текущей общей силой. Результат — ZIP с папками `Glow_01/Glow_01_Before_After.mp4`, `Glow_02/…` и т. д.

Рендер идёт последовательно во время воспроизведения. Оставляйте вкладку открытой. Размер — до 960 px по длинной стороне каждого изображения, SDR; MP4 при поддержке браузера, иначе WebM. Суммарный лимит — 512 МБ. После завершения или отмены восстанавливаются выбранный пресет, слои и позиция видео. Это обзорное видео; мобильное приложение получает отдельный пакет пресетов.

## Совместимость

Adjust, LUT и Bloom используют ранее проверенные мобильные правила. VHS, Soft Blur и Noise имеют приблизительный веб-предпросмотр; экспорт сохраняет штатные мобильные типы и параметры. HDR/P3 и точное поведение декодера телефона не калиброваны.

**Posterize Time — разработка для интеграции в приложение.** Частота задаётся отдельным параметром 5–30 кадров/с (по умолчанию 15). Общая сила 0% отключает эффект, 100% применяет выбранную частоту; между ними результат смешивается с исходным кадром. Нужны persistent-буферы и управление историей со стороны движка. Копирование ZIP само по себе не устанавливает новый шейдер в глобальные ресурсы приложения. [Передача мобильному разработчику](prototypes/posterize-time/README_RU.md).

Оформление использует официальный зелёный знак Movavi Mobile и Aeroport. Источники: [BRAND_GUIDELINES.md](BRAND_GUIDELINES.md).

## Проверки и публикация

Node.js 22+, Python 3.9+:

```sh
node test-mobile-contract.cjs
node test-ranges.cjs
node test-package-import.cjs
node tests/test-isf-mobile.cjs
node tests/posterize-time/test-schedule.cjs
node tests/test-catalog.cjs
python3 test-launcher.py
```

Браузерные проверки требуют Playwright 1.62.1 и Chrome. Запустите локальный сервер, затем:

```sh
node tests/test-workspace.cjs http://127.0.0.1:8766 test-results/workspace
node tests/test-batch-video.cjs http://127.0.0.1:8766 test-results/batch
node tests/posterize-time/browser.cjs http://127.0.0.1:8766 test-results/posterize
```

GitHub Actions проверяет контракт, каталог, создание/переоткрытие пакетов и десять реальных видео со звуком. `tools/build-web.py` собирает статические ресурсы для Pages без пользовательских исходников. Workflow Web app публикует изменения `main`; workflow Release по тегу `v*` собирает автономный ZIP. Результаты: [VALIDATION.md](VALIDATION.md), история: [CHANGELOG.md](CHANGELOG.md).
