# Movavi Effect Builder

Локальный редактор видеопресетов с предпросмотром эффектов и экспортом мобильных пакетов. Текущая версия: **v0.12**.

В ветке `feature/posterize-time` добавлен экспериментальный **Posterize Time**: отдельная кнопка в билдере открывает тестовый пресет и видео. При 0% изображение обновляется 5 раз/с, при 100% сохраняются все исходные кадры. [Инструкция и пакет для мобильного разработчика](prototypes/posterize-time/README_RU.md). На телефоне нужен новый шейдер в ресурсах приложения; мобильная интеграция пока не проверена. Стабильный выпуск v0.12 не изменён.

## Запуск

1. Скачайте ZIP из [Releases](https://github.com/tonysabbatony/movavi-effect-builder/releases) и распакуйте его.
2. Установите Python 3, если он ещё не установлен.
3. На macOS запустите `START_MAC.command`, на Windows — `START_WINDOWS.bat`.
4. Откройте адрес, который напечатает локальный сервер. Для предпросмотра рекомендуется Google Chrome с WebGL2.

Из терминала можно запустить `python3 serve.py`. Приложение работает локально; публикация исходников на GitHub сама по себе не запускает онлайн-редактор.

Подробная инструкция: [README_RU.txt](README_RU.txt). Импорт поддерживает `all_in_one.json` с `Layers.zip` или распакованной папкой `Layers`. Экспорт формирует мобильный пакет с `all_in_one.json` и вложенным `Layers.zip`. Встроенная рабочая подборка находится в `workspace/Dreamy_rework`.

## Разработка и версии

- Ветка `main` содержит текущий код. Изменения удобно делать в отдельных ветках и объединять через pull request.
- Версии отмечаются тегами, например `v0.12`. При отправке нового тега workflow Release выполняет проверки, собирает ZIP и публикует его в Releases.
- Перед новым выпуском обновите номер версии в интерфейсе, сервере, тесте запуска и документации, а также [CHANGELOG.md](CHANGELOG.md).
- Старые папки и ZIP остаются локальным архивом. История Git начинается с импорта v0.12; более ранние изменения не восстановлены задним числом.

## Проверки

Для быстрых проверок нужны Node.js 22+ и Python 3:

```sh
node test-mobile-contract.cjs
node test-ranges.cjs
node test-package-import.cjs
node tests/test-isf-mobile.cjs
python3 test-launcher.py
```

Эти проверки запускаются в GitHub Actions. Они проверяют контракт экспорта, диапазоны параметров, импорт архивов, расчёт общей силы и запуск сервера. Визуальные проверки WebGL/Metal и измеренные ограничения описаны в [VALIDATION.md](VALIDATION.md); они не заменяются этими быстрыми проверками.

Для сравнения с исходным мобильным движком нужен отдельный checkout и Metal v3 reference package. В репозитории сохранены синтетические эталонные кадры и контрольные суммы; личные исходные видео не включены.
